-------------------------------------------------------------------------------
OPTION A — GitHub Actions (recommended, matches the included workflow)
-------------------------------------------------------------------------------
In your GitHub repo: Settings -> Secrets and variables -> Actions -> New repository
secret. Add these four secrets:

  RELEASE_KEYSTORE_BASE64    <- paste the entire contents of fuelgo-release.keystore.base64.txt
  RELEASE_KEYSTORE_PASSWORD  <- lPjDsVrTw0q1xLuyKzSj
  RELEASE_KEY_ALIAS          <- fuelgo-customer
  RELEASE_KEY_PASSWORD       <- lPjDsVrTw0q1xLuyKzSj

The workflow (.github/workflows/build-release.yml) decodes RELEASE_KEYSTORE_BASE64
back into a .keystore file at build time and points Gradle at it — the raw keystore
file itself never touches the git repo.

-------------------------------------------------------------------------------
OPTION B — Building signed releases locally (Android Studio / gradlew)
-------------------------------------------------------------------------------
1. Copy fuelgo-release.keystore somewhere on your machine, e.g. next to (but NOT
   inside) the FuelGoCustomer project folder — e.g. Project/MobileApp/keystore/.
2. Copy FuelGoCustomer/keystore.properties.example to FuelGoCustomer/keystore.properties
   and fill in the real storeFile path + passwords above. This file is git-ignored.
3. Build -> Generate Signed Bundle / APK, or run:
     gradle assembleRelease
   from the FuelGoCustomer folder.
